TP2 – Documentation du programme Python

Mon assistant de révision

1. Présentation

Ce TP consiste à documenter le programme Python « Mon assistant de révision ».

L'objectif du programme est d'aider l'utilisateur à organiser une séance de révision.

Le fichier "main.py" contient le code principal du programme. Il permet de demander des informations à l'utilisateur et d'afficher un message récapitulatif.

2. Évolution du programme : V1 à V4

V1 : Message de bienvenue

Création du programme avec un premier message de bienvenue affiché à l'écran. Cette version a été réalisée localement sur le PC.

V2 : Ajout du prénom

Ajout d'une question pour demander le prénom de l'utilisateur. Après cette modification, le premier "git push" a permis d'envoyer le travail vers GitHub.

V3 : Ajout de la matière

Ajout d'une question pour demander la matière que l'utilisateur souhaite réviser. Cette modification a été réalisée sur GitHub, puis récupérée sur le PC avec la commande "git pull".

V4 : Ajout de la durée

Ajout d'une question pour demander la durée de révision en minutes. Cette modification a été réalisée sur le PC, puis envoyée vers GitHub avec un nouveau "git push".

3. Comment exécuter le programme

Outils nécessaires :

- Un ordinateur Windows.
- Visual Studio Code.
- Python installé.
- L'extension Python dans VS Code.

Étapes d'exécution :

1. Ouvrir le dossier "TP_Git_Python" dans Visual Studio Code.
2. Ouvrir le fichier "main.py".
3. Cliquer sur le bouton ▶ Run Python File en haut à droite.
4. Si nécessaire, choisir l'interpréteur Python.
5. Le terminal intégré s'ouvre automatiquement.
6. Saisir les informations demandées :
   - Le prénom de l'utilisateur.
   - La matière à réviser.
   - La durée de révision en minutes.
7. Valider chaque réponse avec la touche Entrée.

Le programme affiche ensuite un message récapitulatif de la séance de révision.

4. Commandes Git utilisées

- "git init" : permet de créer un dépôt Git local.
- "git add" : permet d'ajouter les fichiers à la zone de préparation.
- "git commit" : permet d'enregistrer les modifications localement.
- "git push" : permet d'envoyer les modifications locales vers GitHub.
- "git pull" : permet de récupérer les modifications depuis GitHub vers le PC.

5. Conclusion

Ce TP m'a permis d'apprendre à documenter un programme Python avec un fichier README.md et à utiliser les principales commandes Git pour gérer les versions d'un projet et travailler avec GitHub.
